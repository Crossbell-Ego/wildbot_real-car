# 🤖 Wildbot 實體小車：逆運動學 (IK) 與 感測器座標補償技術筆記

本文件紀錄了 Wildbot 實體小車在自動抓取任務中的座標系定義、硬體物理偏移、以及軟體補償邏輯。這對於確保 YOLO 3D 偵測與機械手臂精準對位至關重要。

---

## 1. 系統座標系定義 (System Frames)

本系統採用 **ROS 2 標準座標系**：
*   **Base Link (小車中心)**：原點 (0,0,0) 位於小車底盤投影中心。
*   **X 軸 (正數 X+)**：車頭方向（定義為**手臂安裝方向**）。
*   **Y 軸 (正數 Y+)**：左側方向。
*   **Z 軸 (正數 Z+)**：上方方向（離地高度）。

---

## 2. 硬體物理參數與偏移 (Physical Offsets)

經過實體量測與對位修正，最終確定的物理參數如下：

| 組件名稱 | X 軸 (水平位移) | Z 軸 (離地高度) | 角度 (Pitch) | 備註 |
| :--- | :--- | :--- | :--- | :--- |
| **小車中心 (base_link)** | 0.00 cm | 0.00 cm | - | 系統原點 |
| **手臂第一軸 (Shoulder)** | **+16.50 cm** | **12.00 cm** | - | 安裝於車頭最前方 |
| **相機 (Camera)** | **+13.50 cm** | **26.50 cm** | **-20° (Pitch)** | 位於手臂後方 3cm，往下低頭 |

> [!IMPORTANT]
> **Pitch 角度定義**：相機與地面夾角為 70 度，意即相機低頭 20 度。在 URDF 中設置為 `-0.349 rad` 或 `-20 deg`。

---

## 3. 逆運動學 (IK) 模型

系統採用幾何解析法 (Analytical IK) 取代 PyBullet 模擬，以節省 CPU 資源：

*   **手臂結構**：兩軸機械手臂 ($L1 = 80mm$, $L2 = 120mm$)。
*   **抓取極限**：
    *   **最大斜直線距離**：$200.0 mm$ ($20.0 cm$)。
    *   **有效抓取區**：建議水平距離在 $12 \sim 18 cm$ 之間。
*   **座標修正邏輯**：
    ```python
    # 實際目標位置 (Target) 需減去手臂基座位置 (dx, dz)
    dx = target_x - 0.165  # 水平偏移
    dz = target_z - 0.120  # 高度偏移
    dist = sqrt(dx^2 + dz^2) # 計算斜直線距離
    ```

## 4. 軟體修正與補償機制

由於 URDF 轉換與相機驅動 TF 可能存在誤差，系統在 **`detect_3d_node.py`** 中實施了「硬體高度補償」：

*   **Z 軸高度修正**：當偵測到目標物時，系統會自動在 $Z$ 軸上扣除 **20 cm**。
    *   *原因*：原始 TF 轉換會將地面物體誤判為離地 $32\text{ cm}$，扣除 $20\text{ cm}$ 後，物體在 $12\text{ cm}$ 高度（手臂第一軸平面）的座標將顯示為正確的 $12.0\text{ cm}$ 左右。

---

## 5. 自動抓取任務流程 (Grab Task)

為確保安全性，`grab_task.py` 實作了互動式監控模式：

1.  **持續監測**：終端機會即時顯示 `[信心度]`, `[目標座標]`, `[距離手臂距離]`。
2.  **單位顯示**：所有日誌已統一轉換為 **公分 (cm)** 以便對照皮尺。
3.  **手動觸發 (G-Trigger)**：
    *   程式預設**不自動抓取**。
    *   操作者需觀察距離，當距離手臂接近 $15\text{ cm}$ 時，按下鍵盤 **`g`** 鍵啟動。
4.  **安全防護**：
    *   **防燒毀保護**：夾爪閉合後自動退回 2 度，避免馬達過熱。
    *   **可達性檢查**：若目標超出 $15.5\text{ cm}$ 極限，程式會報警告並拒絕動作。
