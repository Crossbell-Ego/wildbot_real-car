### 一、 即時動態調整 (進入容器內執行)

如果您想在小車運行時即時調整亮度，可以使用以下兩種方式：

#### 方式 1：使用 ROS 2 Parameter 調整（最推薦）
進入小車容器後，直接對 `/camera/camera` 節點進行參數設定：

```bash
# 1. 關閉自動曝光（若自動曝光過暗，改為手動調整最有效）
ros2 param set /camera/camera enable_color_auto_exposure false

# 2. 設定曝光時間（值越大越亮，例如 1000 ~ 2000）
ros2 param set /camera/camera color_exposure 1000

# 3. 設定感光增益（值越大越亮，例如 64 ~ 128，過大會產生雜訊）
ros2 param set /camera/camera color_gain 64

# 4. 若要微調亮度偏移 (Brightness Offset)
ros2 param set /camera/camera color_brightness 64
```

#### 方式 2：使用 Orbbec SDK 專屬服務 (Service) 調整
您也可以透過 Service Call 直接向相機硬體發送設定：

```bash
# 關閉自動曝光
ros2 service call /camera/set_color_auto_exposure std_srvs/srv/SetBool "{data: false}"

# 設定曝光值
ros2 service call /camera/set_color_exposure orbbec_camera_msgs/srv/SetInt32 "{data: 1000}"

# 設定增益值
ros2 service call /camera/set_color_gain orbbec_camera_msgs/srv/SetInt32 "{data: 64}"
```

### 二、 永久儲存設定 (修改啟動設定檔)

若要讓每次啟動小車時都自動套用明亮的相機參數，您可以直接修改 [docker-compose_camera_gemini.yml](file:///home/robot/wildbot_real%20car/wildbot_workspace-main/docker/compose/docker-compose_camera_gemini.yml) 檔案。

請在 `dabai` 服務的 `command` 段落中加入對應的啟動參數：

```yaml
services:
  dabai:
    image: ghcr.io/screamlab/wildbot_base_image:latest
    ...
    command:
    - ros2
    - launch
    - orbbec_camera
    - gemini_ew.launch.py    
    - color_width:=1280
    - color_height:=720
    - color_fps:=30
    - depth_width:=1280
    - depth_height:=800
    - depth_fps:=30
    # === 新增以下三行參數來解決亮度過暗的問題 ===
    - enable_color_auto_exposure:=false
    - color_exposure:=1000
    - color_gain:=64
```

修改完成後，下次使用 `sudo ./scripts/00_start_all.sh` 啟動時，相機即會以此亮度設定啟動。
