# 🎮 Wildbot 搖桿功能與編號配置總整理 (ROS 2 `joy_node`)

本文件記錄了目前 Wildbot 實體小車手把（Joystick）在 ROS 2 Jazzy 環境下的真實功能映射與按鍵編號。此配置已於 `joy_to_base_camera.py` 中完美實作，融合了高響應控車與極致安全的手臂防護機制。

---

## 🚀 1. 核心操控佈局 (Chassis & Arm Controls)

### 🚗 A. 底盤移動控制 (Chassis Drive)
底盤的所有運動與速度微調**完全集中於手把左側**，提供極佳的直覺操控與實時精度調節。

| 控制軸 (Axis) | 物理部位 | 動作描述 | 對應 ROS 2 輸出與調節機制 |
| :---: | :---: | :--- | :--- |
| **`axes[1]`** | **左搖桿 上下** | 🚗 前進 / 後退 | `twist.twist.linear.x` (預設最大 `0.45 m/s`，可透過十字鍵上下微調) |
| **`axes[0]`** | **左搖桿 左右** | 🔄 原地旋轉 / 轉向 | `twist.twist.angular.z` (預設最大 `0.40 rad/s`，可透過十字鍵左右微調) |
| **`axes[7]`** = `-1.0` | **十字鍵 上** | 🚀 前進車速加速 | 每次按壓 **調快 `0.05 m/s`**（最大限制 `1.0 m/s`） |
| **`axes[7]`** = `1.0` | **十字鍵 下** | 📉 前進車速減速 | 每次按壓 **調慢 `0.05 m/s`**（最低限制 `0.05 m/s`） |
| **`axes[6]`** = `1.0` | **十字鍵 左** | 🔄 自轉速度加速 | 每次按壓 **調快 `0.05 rad/s`**（最大限制 `2.0 rad/s`） |
| **`axes[6]`** = `-1.0` | **十字鍵 右** | ↩️ 自轉速度減速 | 每次按壓 **調慢 `0.05 rad/s`**（最低限制 `0.05 rad/s`） |

---

### 🦾 B. 手臂水平連動 (Horizontal Linkage)
右搖桿前後專門用於手臂水平連動，小臂在移動中會**自動補償以維持與地面平行（水平）**。

| 控制軸 (Axis) | 物理部位 | 動作描述 | 手臂動作行為 |
| :---: | :---: | :--- | :--- |
| **`axes[3]`** | **右搖桿 前後** | 📏 水平延伸 / 縮回 | **向前推**：手臂水平向前伸長 (Extend)<br>**向後拉**：手臂水平收回 (Retract) |
| **`axes[2]`** | **右搖桿 左右** | ❌ **無功能** | 確保底盤與水平控臂不受左右誤觸干擾 |

---

### 🎛️ C. 手臂關節與夾爪控制 (Joints & Gripper)
使用手把按鈕與類比扳機對夾爪與獨立關節進行精準的控制與微調。

| 按鈕/軸向 (Button/Axis) | 對應部位 | 控制對象 | 物理動作描述 |
| :---: | :---: | :---: | :--- |
| **`axes[4]`** (LT) | **L2 按鍵** | 🦞 **夾爪開合 (開)** | **漸進式張開**：持續按住 L2，夾爪會以 25Hz 頻率平滑張開，最大至 $240^\circ$ (4.19 rad) 全開 |
| **`axes[5]`** (RT) | **R2 按鍵** | 🦞 **夾爪開合 (合)** | **漸進式閉合**：持續按住 R2，夾爪會以 25Hz 頻率平滑閉合，最緊至防燒毀極限 $168^\circ$ (2.93 rad) |
| **`buttons[4]`** | **Y** (最上方) | **大臂 (Joint 1)** | 抬升大臂 (減少 `arm_1_joint` 角度，單次增量 0.040 rad) |
| **`buttons[0]`** | **A** (最下方) | **大臂 (Joint 1)** | 降低大臂 (增加 `arm_1_joint` 角度，單次增量 0.040 rad) |
| **`buttons[2]`** / **`3`** | **X** (最左側) | **小臂 (Joint 2)** | 抬升小臂 (減少 `arm_2_joint` 角度，單次增量 0.040 rad) |
| **`buttons[1]`** | **B** (最右側) | **小臂 (Joint 2)** | 降低小臂 (增加 `arm_2_joint` 角度，單次增量 0.040 rad) |

---

### 🚨 D. 系統安全與防護機制 (Safety & Guard)
高規格競賽級安全保障，一鍵瞬停，開機防衝。

| 按鈕/機制 | 物理部位 | 功能類型 | 動作行為與保護邏輯 |
| :---: | :---: | :---: | :--- |
| **`buttons[6]`** | **L1 / LB** | **緊急即停 (E-Stop)** | **Toggle 切換鎖**：按一下強制停死底盤與手臂，再次按下解鎖。鎖定狀態下無視一切手把輸入。 |
| **`node_start_time`** | **系統自動** | **啟動防暴衝保護** | 忽略啟動前 **1.5 秒** 的任何手把數據，防止初始扳機偏置與未歸零訊號引發手臂隨機移動。 |
| **`arm_1_joint` 零點** | **系統自動** | **無效零位保護鎖** | 當 ROS 2 Control 尚未與物理串口通訊完成前（數據為 0.0 rad時），強制鎖死手臂控制，直至讀取到實體角度，防止跳躍。 |

## 🛠️ 2. 手把測試與除錯指南

若日後更換不同型號的手把或遇到映射跑掉，請按照以下步驟在 Docker 容器內進行查驗：

1. **進入運行中容器**：
   ```bash
   docker exec -it compose-kros_car-1 bash
   ```
2. **列印手把主題數據**：
   ```bash
   ros2 topic echo /joy
   ```
3. **對照觀測**：
   觀察 `axes`（浮點數數組）與 `buttons`（整數數組）的索引變動，即可輕鬆獲得新把手的物理映射關係！
