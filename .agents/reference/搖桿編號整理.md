# 🎮 Wildbot 搖桿編號與功能對應表 (ROS 2 `joy_node`)

這份文件記錄了目前把手（Joystick）在 ROS 2 環境下的編號映射，適用於 `joy_to_base_camera.py` 等控制腳本。

## 1. 搖桿軸 (Axes)
| 編號 (Index) | 對應部位             | 動作描述          | 備註                                             |
| :----------- | :------------------- | :---------------- | :----------------------------------------------- |
| **0**        | 左搖桿 (Left Stick)  | 左右 (Horizontal) | 用於控制底盤左右轉向 / 橫移                      |
| **1**        | 左搖桿 (Left Stick)  | 上下 (Vertical)   | 用於控制底盤前進與後退                           |
| **2**        | 右搖桿 (Right Stick) | 左右 (Horizontal) | 通常用於控制相機雲台左右轉或手臂旋轉             |
| **3**        | 右搖桿 (Right Stick) | 上下 (Vertical)   | 通常用於控制手臂高度，同時手臂第二軸可以保持水平 |
| **4**        | L2 按鍵 (LT)         | 類比壓力          | 預設值為 `1.0`，按到底會變為 `0.0` 或 `-1.0`     |
| **5**        | R2 按鍵 (RT)         | 類比壓力          | 預設值為 `1.0`，按到底會變為 `0.0` 或 `-1.0`     |
| **6**        | 方向鍵 (D-Pad)       | 左右              | 某些把手會映射為 Axes                            |
| **7**        | 方向鍵 (D-Pad)       | 上下              | 某些把手會映射為 Axes                            |

## 2. 按鈕 (Buttons)
*目前測試中尚未觸發，一般常用配置如下：*
| 編號 (Index) | 對應按鈕       | 常見功能建議        |
| :----------- | :------------- | :------------------ |
| **0**        | A / X (最下方) | 夾爪閉合 / 動作執行 |
| **1**        | B / O (右側)   | 夾爪開啟 / 取消動作 |
| **2**        | X / □ (左側)   | -                   |
| **3**        | Y / △ (最上方) | -                   |
| **4**        | L1 (LB)        | 低速模式切換        |
| **5**        | R1 (RB)        | 加速模式切換        |

---

## 🔍 如何再次確認編號？
若更換把手，請進入容器執行：
```bash
ros2 topic echo /joy
```
觀察 `axes` 與 `buttons` 陣列中數值的變動順序即為編號（從 0 開始計算）。
